My Ritual · 每日护理计划

1. 本地使用
   下载 skincare_routine.html，在电脑浏览器中打开即可离线使用。
   在手机上可保存到“文件”App，再尝试从支持 HTML 的浏览器打开。

2. 生成可随时访问的网页链接（推荐）
   将 index.html 上传至你自己的 GitHub Pages 网站仓库的一个子文件夹，例如 skincare/index.html，提交并发布后，即可通过 https://你的用户名.github.io/skincare/ 访问。
   也可以新建独立仓库，启用 Settings > Pages > Deploy from a branch。

3. 打卡记录
   页面使用浏览器 localStorage 储存，数据不会上传到服务器。不同浏览器、不同手机之间不会自动同步。
   如果以“文件”方式打开，部分手机浏览器可能限制本地储存。发布到 HTTPS 网站后通常更可靠。
